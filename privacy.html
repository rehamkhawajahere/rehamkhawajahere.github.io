Privacy Policy

Money Gap Uploader is a private tool operated by the owner of The Money Gap channel. It is used only to upload the owner's own original videos to the owner's own YouTube channel, Facebook Page and Instagram account.

Data we access

The tool uses Google OAuth to obtain permission to upload videos and set thumbnails on the owner's YouTube channel. It accesses no other user's account and requests no personal data from viewers.

How data is used and stored

Access tokens are stored as encrypted secrets in a private GitHub repository and are used solely to upload videos. No user data is sold, shared with third parties, or used for advertising.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. This tool uses the YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
